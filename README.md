# Sterio Phone — website

Marketing and help site for **Sterio Phone**, which lets a SIM-less iPhone act as the handset for the Android phone that holds your SIM.

Plain HTML, CSS and JavaScript — no framework, no build step, no cookies, no analytics, no external requests.

## Pages

Home · How it works · Features · Requirements · Setup guide · Shizuku guide · Privacy & security · Early access · FAQ · Support · Privacy policy · Terms

## Run locally

```bash
python3 -m http.server 8000   # then open http://localhost:8000
```

## Structure

```
css/styles.css   styles
js/main.js       navigation, tabs, FAQ search, video chapters
assets/          icons, social image, fonts, videos
downloads/       Android app
```

## Content guidelines

Keep the site focused on what users do and get. Don't publish technical details about how the apps work internally (protocols, formats, frameworks, system interfaces).
