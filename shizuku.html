What Shizuku is, and why Sterio Phone needs it

Shizuku is a free, open-source helper app that Sterio Phone needs on the Android phone. You set it up once.

  • Shizuku is made by an independent developer (RikkaApps), not by us.
  • You stay in control: it asks your permission before Sterio Phone can use it, and you can remove access any time.
  • Starting it needs Android 11 or newer and a Wi-Fi connection. Sterio Phone itself needs Android 12 or newer.

Before you begin: connect both phones to the same Wi-Fi network, temporarily. Android doesn’t let you switch on Wireless debugging unless it’s connected to Wi-Fi, and your iPhone needs to be on the same network to pair with it.

Official sources: Shizuku’s own user manual is the reference. This page walks through the same steps for Sterio Phone users.

1 · Install Shizuku

Install it on the Android phone that holds your SIM — the same phone that runs Sterio Phone. Pick any one of these:

Google Play

Easiest. Search “Shizuku” or open the listing.

GitHub releases

Download the latest APK from the developer’s repository.

Official site

The Shizuku website’s own download page.

2 · Turn on Developer options

  1. Show Developer options

    Open Settings → About phone and tap Build number about seven times until you see “You are now a developer”. On some phones Build number is under Software information or Version.

  2. Find Developer options

    It’s now in Settings → System → Developer options (on some phones: Additional settings → Developer options). Turn the main switch on.

  3. Check USB debugging is on (recommended)

    If Developer options shows USB debugging, leave it switched on — Shizuku’s own guide lists it as a prerequisite and says Shizuku can stop working if it is switched off. You’ll do the actual starting with Wireless debugging in the next step.

Realme, Oppo and OnePlus (ColorOS): also turn off “Permission monitoring” in Developer options. Otherwise Shizuku may not start properly. Xiaomi / POCO (MIUI, HyperOS): turn on “USB debugging (Security settings)”, which is separate from “USB debugging”.

3 · Turn on Wireless debugging

  1. Connect both phones to the same Wi-Fi

    Join the same Wi-Fi network on your Android phone and your iPhone — just for setup. If the Android phone isn’t on Wi-Fi, the Wireless debugging switch stays greyed out or turns itself off.

  2. Open Wireless debugging

    In Developer options, tap Wireless debugging and switch it on. If Android asks “Allow wireless debugging on this network?”, choose Allow.

4 · Pair Shizuku (one time only)

Pairing tells Android that Shizuku is allowed to use Wireless debugging. You only do this once.

  1. Open Shizuku and choose pairing

    Open the Shizuku app and tap Start via Wireless debugging, then Pairing. If Shizuku shows a notification asking for the pairing code, leave it there.

  2. Show the pairing code

    Go to Developer options → Wireless debugging and tap Pair device with pairing code. A six-digit code appears.

  3. Enter the code in Shizuku’s notification

    Pull down the notification shade, tap Enter pairing code on Shizuku’s notification, and type the six digits. Shizuku confirms the pairing.

    Tip: keep the pairing-code dialog open while you do this — closing it cancels the pairing.

5 · Start Shizuku

  1. Tap Start

    In Shizuku, tap Start under “Start via Wireless debugging”. Wait a few seconds.

  2. Check it’s running

    The Shizuku home screen should say “Shizuku is running”. If it doesn’t start, turn Wireless debugging off and on again, then tap Start once more.

6 · Approve Sterio Phone

  1. Open Sterio Phone

    In the Sterio Phone Android app, follow the guided setup. When it asks for Shizuku access, a Shizuku permission dialog appears.

  2. Allow

    Choose Allow all the time (or the equivalent). Then tap Start host in Sterio Phone. You’re done — head back to the setup guide to pair your iPhone.

After you restart your phone

Android stops Shizuku whenever the phone restarts. After a reboot, repeat only steps 3 and 5 (turn on Wireless debugging on Wi-Fi, then tap Start in Shizuku). You don’t need to pair again. Then open Sterio Phone and tap Start host.

Alternative: start from a computer

If Wireless debugging won’t cooperate, Shizuku’s official manual describes starting it from a computer with a USB cable. Follow the official user manual, then continue from step 6 above.

Troubleshooting

Shizuku keeps saying “Searching for pairing service”

Let Shizuku run in the background. In your phone’s battery or app settings, set Shizuku to Unrestricted / allow background activity, and make sure it has local-network access. Many phones cut off an app’s network the moment it leaves the screen, and pairing needs that connection. Keep the pairing-code dialog open while you enter the code from the notification.

It fails as soon as I tap “Enter pairing code”

On Xiaomi / POCO phones, switch the notification style to Android (Settings → Notifications → Notification shade). The inline reply field doesn’t work with the default style.

It starts, but Sterio Phone says access is limited

Your phone maker may be restricting developer access. Realme / Oppo / OnePlus: turn off “Permission monitoring” in Developer options. Xiaomi / POCO: turn on “USB debugging (Security settings)”. Meizu: turn off “Flyme payment protection”. Then start Shizuku again.

Shizuku stops by itself

Keep Shizuku allowed to run in the background, and don’t turn off USB debugging or Developer options. Under Developer options, set the default USB configuration to No data transfer / Charge only, and on Android 11+ turn on the option that disables the authorization timeout, if you see it. On Xiaomi phones, avoid the Security app’s scan feature, which can switch debugging off.

Wireless debugging won’t turn on

Wireless debugging only works while the Android phone is connected to Wi-Fi. Connect both phones to the same Wi-Fi network temporarily (a phone hotspot from another device works too), then switch it on. If you have no Wi-Fi at all, see the computer option above.

Sterio Phone stopped working after my phone restarted

That’s expected: Shizuku stops on every restart. Turn Wireless debugging on, open Shizuku, tap Start, then tap Start host in Sterio Phone.
