From two phones to one phone line

Set up the Android phone first, then the iPhone, then pair them and make a test call.

Early access guide. Download the Android app from the early access page; the iPhone app is shared by request.

Before you begin: connect both phones to the same Wi-Fi network, temporarily. Android only lets you turn on Wireless debugging while it’s connected to Wi-Fi, and the two phones need to be on the same network to pair.

  1. Install the Sterio Phone host

    Download the APK from the early access page and open it. Android may ask you to allow installs from your browser or file manager.

  2. Connect to Wi-Fi, then turn on Developer options and Wireless debugging

    First join the same Wi-Fi network as your iPhone (temporarily — Wireless debugging can’t be switched on without Wi-Fi). Then Settings → About phone → tap Build number seven times, and in Developer options turn Wireless debugging on.

  3. Install and start Shizuku

    Sterio Phone needs a free helper app called Shizuku. Install it, start it with Wireless debugging, then approve Sterio Phone when asked. Follow the full Shizuku guide →

    After any Android reboot you need to start Shizuku again.

  4. Open Sterio Phone and follow the guided setup

    Grant the phone, call-log, notification and battery permissions the app lists, then tap Start host. A persistent notification confirms it’s running.

  1. Install the Sterio Phone iPhone app

    During early access we send you the iPhone app together with simple install instructions.

  2. Trust the developer certificate

    Settings → General → VPN & Device Management → trust the developer profile. Turn on Developer Mode if iOS asks.

  3. Join the same network

    Connect the iPhone to the same Wi-Fi as the Android phone — or join the Android phone’s hotspot, which works anywhere there’s signal.

  4. Open the app and accept the consent screens

    Allow Local Network and Microphone. Contacts are optional but give you caller names.

  1. Pair

    In the iPhone app tap Scan QR and point it at the code on the Android app — or choose Enter code and type the short pairing code. The phones can also find each other automatically.

  2. Check the Phone tab

    You should see the Android phone’s battery, signal and SIM status. That confirms the link is healthy.

  3. Test a call

    Call your Android number from another phone. The iPhone should ring; tap Accept and talk. Then dial a friend from the keypad.

  4. Keep it reliable

    Leave the Android phone charging with the host notification showing, and exempt it from battery optimisation. If something misbehaves, use Share diagnostics in the iPhone app and send it to us.
